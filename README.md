## 🚀 Instant GitHub Pages Deployment Guide

To deploy this site directly under your GitHub account (`https://github.com/lkpadmanaban`):

### Option 1: Main User Page (`lkpadmanaban.github.io`)
1. Create a new repository on GitHub named **`lkpadmanaban.github.io`**.
2. Run the following commands inside this directory:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of executive architecture website"
   git branch -M main
   git remote add origin https://github.com/lkpadmanaban/lkpadmanaban.github.io.git
   git push -u origin main
   ```
3. In GitHub Repository Settings -> **Pages**:
   - Source: **Deploy from a branch** (Branch: `main`, Folder: `/root`) OR select **GitHub Actions**.
4. Your site will automatically go live at **`https://lkpadmanaban.github.io/`**!
